# Publish FloodWatch

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then click **Save**.
5. Wait for GitHub Pages to finish. The expected URL is `https://pantheondeified.github.io/FloodWatch-South-India/`.

The site requires internet access to load its map tiles and public APIs. It is a prototype, not an official warning service.
