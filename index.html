Rain → catchment → river → flood evidence


This panel connects available evidence in time order. It is not a deterministic rule that heavy rain always causes a flood. A valid flood conclusion needs a connected upstream catchment, a relevant river observation or forecast, local thresholds, and evidence from past events.

Forecast models & flood evidence


We separate external model output from FloodWatch's own research code. A forecast is not treated as a verified river-gauge measurement.




AWeather & rainfall
Available
Open-Meteo point forecast and historical ERA5-Land estimates. Reanalysis is not a direct rain-gauge reading.


BRiver-flow outlook
External model
GloFAS river-discharge estimates/forecast via Open-Meteo when data are available. This is not a FloodWatch-trained model or live measured river height.


CFloodWatch neural network
Training code only
An LSTM training script exists, but no locally trained and validated South India model is currently published. No local NN forecast is presented as operational.


DFlood extent & depth
Not forecast here
Historical satellite flood extents and terrain/hydraulic-model work are research inputs; this map does not currently predict inundation depth.
